Pour créer une disposition en vignettes avec deux images par ligne en utilisant Card dans Jetpack Compose, tu peux intégrer une Card autour de chaque image dans ta grille, tout en gardant la structure avec LazyVerticalGrid. L’idée est d’utiliser des cartes (Card) pour chaque élément de la grille afin d’obtenir des effets de profondeur, de coins arrondis, et d'ombre.

Voici un exemple complet avec des Card pour chaque élément de la grille :
1. Mise à jour du code avec des Card pour chaque image

package com.example.vignettesgrid

import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.compose.foundation.Image
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.lazy.LazyVerticalGrid
import androidx.compose.foundation.lazy.grid.GridCells
import androidx.compose.material3.Card
import androidx.compose.material3.CardElevation
import androidx.compose.material3.MaterialTheme
import androidx.compose.material3.Surface
import androidx.compose.runtime.Composable
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.layout.ContentScale
import androidx.compose.ui.res.painterResource
import androidx.compose.ui.unit.dp
import com.example.vignettesgrid.ui.theme.VignettesGridTheme

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            VignettesGridTheme {
                Surface(modifier = Modifier.fillMaxWidth(), color = MaterialTheme.colorScheme.background) {
                    GridWithCards()
                }
            }
        }
    }
}

@Composable
fun GridWithCards() {
    // Liste des images à afficher
    val imageList = listOf(
        R.drawable.image1, R.drawable.image2, R.drawable.image3, R.drawable.image4,
        R.drawable.image5, R.drawable.image6, R.drawable.image7, R.drawable.image8
    )

    // LazyVerticalGrid avec 2 colonnes
    LazyVerticalGrid(
        columns = GridCells.Fixed(2),  // 2 colonnes par ligne
        contentPadding = PaddingValues(8.dp)
    ) {
        items(imageList.size) { index ->
            Card(
                modifier = Modifier
                    .padding(8.dp) // Espacement entre les cartes
                    .fillMaxWidth(),
                elevation = CardElevation(6.dp),  // Ombre sous chaque Card
                shape = androidx.compose.foundation.shape.RoundedCornerShape(12.dp), // Coins arrondis
                backgroundColor = Color.White
            ) {
                // Contenu de la Card : une Image
                Image(
                    painter = painterResource(id = imageList[index]),
                    contentDescription = "Image $index",
                    modifier = Modifier
                        .fillMaxWidth()
                        .height(200.dp), // Hauteur fixe pour chaque image
                    contentScale = ContentScale.Crop // L'image se redimensionne pour remplir l'espace sans déformation
                )
            }
        }
    }
}


2. Explications du code :
LazyVerticalGrid :

    LazyVerticalGrid(columns = GridCells.Fixed(2)) : Utilise une grille avec 2 colonnes par ligne. Les éléments s'adaptent automatiquement pour se répartir sur deux colonnes.

    contentPadding = PaddingValues(8.dp) : Ajoute de l'espace autour de la grille pour éviter que les éléments ne soient collés aux bords.

Card :

    Card est utilisé ici pour chaque image. Les cartes permettent d’ajouter des coins arrondis, des ombres, et un fond.

        elevation = CardElevation(6.dp) : Définit une élévation de la carte, ce qui ajoute une ombre sous la carte et donne un effet de profondeur.

        shape = RoundedCornerShape(12.dp) : Définit des coins arrondis pour chaque carte. Plus la valeur est grande, plus les coins seront arrondis.

        backgroundColor = Color.White : Définit la couleur de fond de la carte.

        modifier = Modifier.padding(8.dp) : Ajoute de l'espace entre les cartes de la grille.

Image :

    Image : L'image est chargée à partir de la ressource avec painterResource. L'image est mise à l'échelle avec ContentScale.Crop pour remplir la Card sans déformation, mais avec une coupe si nécessaire.

        modifier = Modifier.fillMaxWidth().height(200.dp) : Fait en sorte que l'image prenne toute la largeur disponible de la Card tout en ayant une hauteur fixe de 200 dp.

3. Configurer les ressources d'images :

Tu dois ajouter des images dans le dossier res/drawable de ton projet Android. Par exemple, tu peux ajouter des images comme image1.jpg, image2.jpg, etc. pour que le code les charge correctement.
4. Personnalisation de l'interface :

    Espacement : La fonction padding dans le Card définit l'espacement entre les cartes de la grille. Tu peux ajuster cette valeur pour avoir plus ou moins d'espace entre les éléments.

    Animations et interactions : Si tu veux ajouter des interactions comme un onClick sur chaque image ou des animations d'entrée, tu peux facilement intégrer des éléments comme Modifier.clickable ou des transitions animées avec Compose.

5. Résultat final :

En exécutant cette application, tu verras une grille de vignettes avec des Card pour chaque image. Chaque élément de la grille aura des coins arrondis, une ombre (grâce à l'élévation), et un espacement entre eux pour créer une interface esthétique et moderne.
Conclusion

Jetpack Compose rend la création de grilles de vignettes très simple, surtout avec des composants comme LazyVerticalGrid et Card. En ajoutant des cartes avec des coins arrondis et des ombres, tu peux facilement créer une interface propre et professionnelle.

Outil Jenkins avec PHPUnit et JUnit
JUnit teste le code. Jenkins lance les tests (et plein d’autres étapes).

Un exemple concret :
- Tu fais un git push
- Jenkins se déclenche
- Jenkins lance mvn test
- JUnit exécute les tests
- Jenkins récupère les résultats et dit ?? ou ?

Jenkins : pipeline CI/CD de build (qualité, sécurité) puis release (outils de dépendances)

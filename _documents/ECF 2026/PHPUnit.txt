écrire des tests unitaires et fonctionnels pour le log-in d'une application pur php avec PHP UNIT

Parfait ! On va aborder ça étape par étape. Je vais te montrer comment écrire des tests unitaires et fonctionnels pour le login d’une application PHP pure (sans framework comme Laravel, Symfony, etc.). On supposera que l’application utilise une base de données simple et que le login est basé sur un username et password.

1️⃣ Préparer l’environnement de test

Pour PHP, le standard est PHPUnit pour les tests unitaires et fonctionnels.

Installer PHPUnit

Si ce n’est pas déjà fait : composer require --dev phpunit/phpunit

Crée un fichier phpunit.xml à la racine de ton projet :

5️⃣ Lancer les tests
vendor/bin/phpunit

Tu verras le résultat pour chaque test, et tu pourras ajouter des cas (ex. utilisateur verrouillé, champs vides, injection SQL, etc.).

💡 Conseils pratiques :

Séparer la logique de l’affichage : Auth.php contient la logique, login.php juste le HTML.

Utiliser des mots de passe hashés dans les tests.

Pour les tests fonctionnels plus avancés, tu peux utiliser Symfony Panther ou Goutte pour simuler un vrai navigateur.

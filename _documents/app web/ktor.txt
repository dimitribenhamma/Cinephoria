Ktor (Api en Jetpack compose)
D'accord, pour créer un endpoint d'une API JSON en utilisant Kotlin, Jetpack Compose, et Ktor pour consommer une API externe, voici un guide détaillé avec un exemple complet.
Nous allons créer une application Kotlin avec Jetpack Compose pour afficher les données récupérées d'une API JSON. Pour ce faire, nous allons :
1.	Configurer les dépendances pour Jetpack Compose et Ktor.
2.	Créer un modèle de données pour désérialiser le JSON.
3.	Créer une fonction qui récupère les données à partir de l'API.
4.	Utiliser un ViewModel pour gérer l'état.
5.	Créer une interface utilisateur avec Jetpack Compose qui affichera les données.

Étape 2 : Créer un modèle de données
Ensuite, crée un modèle de données pour désérialiser la réponse JSON de l'API. Imaginons que l'API renvoie un objet Person.
import kotlinx.serialization.Serializable

@Serializable
data class Person(
    val id: Int,
    val name: String,
    val age: Int
)
Étape 3 : Créer une fonction pour appeler l'API avec Ktor
Voici la fonction qui utilise Ktor pour effectuer une requête GET à l'API et récupérer les données JSON. Nous allons également configurer la sérialisation JSON avec kotlinx.serialization.
import io.ktor.client.*
import io.ktor.client.engine.android.*
import io.ktor.client.request.*
import io.ktor.client.plugins.contentnegotiation.*
import io.ktor.serialization.kotlinx.json.*
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import kotlinx.serialization.json.Json

suspend fun fetchPersonFromApi(): Person? {
    val client = HttpClient(Android) {
        install(ContentNegotiation) {
            json(Json { ignoreUnknownKeys = true })
        }
    }

    return try {
        val response: Person = client.get("https://api.example.com/person/1") // Change l'URL de l'API ici
        response
    } catch (e: Exception) {
        e.printStackTrace()
        null
    } finally {
        client.close()
    }
}
Étape 4 : Créer un ViewModel pour gérer l'état
Le ViewModel va gérer l'appel réseau et l'état de l'interface utilisateur (par exemple, chargé, échec, ou succès). Voici un exemple de ViewModel.
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.getValue
import androidx.compose.runtime.setValue
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import kotlinx.coroutines.launch

class PersonViewModel : ViewModel() {

    var person by mutableStateOf<Person?>(null)
        private set

    var isLoading by mutableStateOf(false)
        private set

    var errorMessage by mutableStateOf<String?>(null)
        private set

    fun fetchPersonData() {
        isLoading = true
        errorMessage = null
        viewModelScope.launch {
            try {
                val result = fetchPersonFromApi()
                person = result
            } catch (e: Exception) {
                errorMessage = "Failed to fetch data"
            } finally {
                isLoading = false
            }
        }
    }
}
Étape 5 : Créer une interface utilisateur avec Jetpack Compose
Maintenant, créons une interface utilisateur simple avec Jetpack Compose pour afficher les données récupérées. Nous allons afficher un indicateur de chargement pendant que les données sont récupérées.
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.text.BasicText
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.tooling.preview.Preview
import androidx.lifecycle.viewmodel.compose.viewModel

@Composable
fun PersonScreen(personViewModel: PersonViewModel = viewModel()) {
    // Observer les changements d'état dans le ViewModel
    val person = personViewModel.person
    val isLoading = personViewModel.isLoading
    val errorMessage = personViewModel.errorMessage

    // Charger les données au démarrage de l'écran
    LaunchedEffect(Unit) {
        personViewModel.fetchPersonData()
    }

    // Interface utilisateur
    Scaffold(
        topBar = {
            TopAppBar(
                title = { Text("Person Info") }
            )
        },
        content = {
            Column(
                modifier = Modifier
                    .fillMaxSize()
                    .padding(16.dp),
                horizontalAlignment = Alignment.CenterHorizontally,
                verticalArrangement = Arrangement.Center
            ) {
                if (isLoading) {
                    CircularProgressIndicator()
                } else {
                    person?.let {
                        Text("ID: ${it.id}", style = MaterialTheme.typography.body1)
                        Text("Name: ${it.name}", style = MaterialTheme.typography.body1)
                        Text("Age: ${it.age}", style = MaterialTheme.typography.body1)
                    }

                    errorMessage?.let {
                        Text(it, style = MaterialTheme.typography.body2)
                    }
                }
            }
        }
    )
}

@Preview(showBackground = true)
@Composable
fun PreviewPersonScreen() {
    PersonScreen()
}
Étape 6 : Lancer l'application
Dans ta MainActivity, configure Jetpack Compose pour afficher l'écran.
import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.compose.material3.MaterialTheme
import androidx.compose.material3.Surface
import androidx.compose.ui.tooling.preview.Preview
import com.example.apiwithcompose.ui.theme.ApiWithComposeTheme

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            ApiWithComposeTheme {
                // Applique la surface et ton écran
                Surface(modifier = Modifier.fillMaxSize(), color = MaterialTheme.colorScheme.background) {
                    PersonScreen()  // Affiche l'écran de la personne
                }
            }
        }
    }
}
Résumé des étapes :
1.	Ktor est utilisé pour récupérer les données depuis l'API.
2.	Le ViewModel gère les appels réseau et l'état de l'interface (chargement, données récupérées, ou erreur).
3.	Jetpack Compose est utilisé pour afficher ces données dans une interface réactive.

Ton interface affichera les détails de la personne (ID, Nom, Âge).

disposition en vignettes 2 images par lignes en android jetpack compose avec card à partir d'une api

Si tu souhaites afficher des images en vignettes avec des Card dans une disposition de 2 images par ligne à partir d’une API dans Jetpack Compose, tu vas devoir récupérer des données depuis l'API, les afficher dans une grille, et ajouter un Card autour de chaque image.

Je vais te montrer comment récupérer les images depuis une API, les afficher dans une grille avec deux images par ligne, et les envelopper dans des Card.
Étapes :

    Récupérer les données depuis l'API.

    Afficher ces données dans une LazyVerticalGrid.

    Afficher chaque image dans une Card.

    Gérer les erreurs et afficher des indicateurs de chargement.

Je vais te donner un exemple complet en utilisant Retrofit pour l’appel API et Jetpack Compose pour l’affichage de la grille.
1. Ajouter les dépendances nécessaires

Dans ton fichier build.gradle (Module), ajoute les dépendances suivantes pour Retrofit (pour récupérer les données de l'API) et Jetpack Compose :

dependencies {
    // Jetpack Compose
    implementation "androidx.compose.ui:ui:1.4.0" // Utilise la dernière version de Compose
    implementation "androidx.compose.material:material:1.4.0"
    implementation "androidx.compose.foundation:foundation:1.4.0"
    implementation "androidx.compose.runtime:runtime:1.4.0"
    implementation "androidx.compose.foundation:foundation-layout:1.4.0"

    // Retrofit + Gson pour l'API
    implementation "com.squareup.retrofit2:retrofit:2.9.0"
    implementation "com.squareup.retrofit2:converter-gson:2.9.0"

    // OkHttp pour les logs de requêtes (optionnel)
    implementation "com.squareup.okhttp3:logging-interceptor:4.9.1"

    // Coil pour charger les images
    implementation "io.coil-kt:coil-compose:2.2.2"
}


2. Créer une API Service avec Retrofit

Supposons que tu as une API qui retourne une liste d'images dans un format JSON comme suit :

[
  {
    "url": "https://example.com/image1.jpg",
    "title": "Image 1"
  },
  {
    "url": "https://example.com/image2.jpg",
    "title": "Image 2"
  }
  // ...
]


Tu peux créer un service Retrofit comme suit :

data class ImageItem(
    val url: String,
    val title: String
)


b. Créer un API Service avec Retrofit

import retrofit2.Call
import retrofit2.http.GET

interface ApiService {
    @GET("images")  // Remplace par ton endpoint réel
    suspend fun getImages(): List<ImageItem>
}


c. Configurer Retrofit

import okhttp3.OkHttpClient
import retrofit2.Retrofit
import retrofit2.converter.gson.GsonConverterFactory

object RetrofitInstance {
    private const val BASE_URL = "https://example.com/api/" // Remplace par ton URL

    private val retrofit by lazy {
        Retrofit.Builder()
            .baseUrl(BASE_URL)
            .addConverterFactory(GsonConverterFactory.create())
            .client(OkHttpClient.Builder().build())
            .build()
    }

    val apiService: ApiService by lazy {
        retrofit.create(ApiService::class.java)
    }
}


3. Afficher les images dans une LazyVerticalGrid avec des Card

Maintenant que tu as configuré l'API et que tu peux récupérer des images, tu peux utiliser Jetpack Compose pour afficher ces images dans une grille.
a. Créer une fonction composable pour afficher la grille

import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.compose.foundation.Image
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.lazy.LazyVerticalGrid
import androidx.compose.foundation.lazy.grid.GridCells
import androidx.compose.foundation.lazy.grid.items
import androidx.compose.material3.Card
import androidx.compose.material3.CardElevation
import androidx.compose.material3.MaterialTheme
import androidx.compose.material3.Surface
import androidx.compose.runtime.Composable
import androidx.compose.runtime.LaunchedEffect
import androidx.compose.runtime.remember
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.layout.ContentScale
import androidx.compose.ui.res.painterResource
import androidx.compose.ui.unit.dp
import coil.compose.rememberImagePainter
import com.example.vignettesgrid.ui.theme.VignettesGridTheme
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContent {
            VignettesGridTheme {
                Surface(modifier = Modifier.fillMaxWidth(), color = MaterialTheme.colorScheme.background) {
                    ImagesGrid()
                }
            }
        }
    }
}

@Composable
fun ImagesGrid() {
    // Appeler l'API pour récupérer les images
    val images = remember { mutableStateOf<List<ImageItem>>(emptyList()) }

    LaunchedEffect(Unit) {
        try {
            // Effectuer l'appel API sur un thread d'arrière-plan
            val result = withContext(Dispatchers.IO) {
                RetrofitInstance.apiService.getImages()
            }
            images.value = result
        } catch (e: Exception) {
            // Gérer l'erreur de l'API
            println("Error fetching images: ${e.localizedMessage}")
        }
    }

    // Afficher les images dans une LazyVerticalGrid
    LazyVerticalGrid(
        columns = GridCells.Fixed(2),  // 2 images par ligne
        contentPadding = PaddingValues(8.dp)
    ) {
        items(images.value) { imageItem ->
            ImageCard(imageItem)
        }
    }
}

@Composable
fun ImageCard(imageItem: ImageItem) {
    Card(
        modifier = Modifier
            .padding(8.dp)  // Espacement entre les cartes
            .fillMaxWidth(),
        elevation = CardElevation(6.dp),  // Ombre sous chaque Card
        shape = androidx.compose.foundation.shape.RoundedCornerShape(12.dp), // Coins arrondis
        backgroundColor = Color.White
    ) {
        // Utiliser Coil pour charger l'image depuis l'URL
        Image(
            painter = rememberImagePainter(imageItem.url),
            contentDescription = imageItem.title,
            modifier = Modifier
                .fillMaxWidth()
                .height(200.dp), // Hauteur fixe pour chaque image
            contentScale = ContentScale.Crop // L'image se redimensionne pour remplir l'espace sans déformation
        )
    }
}


Explication du code :

    Récupération des données depuis l'API :

        LaunchedEffect(Unit) : Cette fonction permet de lancer une coroutine pour effectuer l'appel API lorsque la composable est rendue pour la première fois.

        remember { mutableStateOf(...) } : Utilisé pour stocker et mettre à jour la liste des images de manière réactive.

        withContext(Dispatchers.IO) : Cette fonction permet d'exécuter la récupération des données de l'API sur un thread d'arrière-plan.

    LazyVerticalGrid :

        Utilisation de LazyVerticalGrid pour afficher une grille de 2 images par ligne. La propriété GridCells.Fixed(2) définit le nombre de colonnes.

    ImageCard :

        Chaque image est affichée dans une Card avec des coins arrondis et une ombre.

        rememberImagePainter(imageItem.url) charge l'image à partir de l'URL de l'API en utilisant Coil, une bibliothèque pour le chargement d'images.

4. Afficher des erreurs et gérer les états de chargement

Si tu veux ajouter un indicateur de chargement ou un message d’erreur, tu peux afficher un ProgressIndicator lorsque les données sont en cours de chargement.

import androidx.compose.material3.CircularProgressIndicator
import androidx.compose.runtime.getValue
import androidx.compose.runtime.setValue

@Composable
fun ImagesGrid() {
    var images by remember { mutableStateOf<List<ImageItem>>(emptyList()) }
    var isLoading by remember { mutableStateOf(true) }

    LaunchedEffect(Unit) {
        try {
            val result = withContext(Dispatchers.IO) {
                RetrofitInstance.apiService.getImages()
            }
            images = result
        } catch (e: Exception) {
            println("Error fetching images: ${e.localizedMessage}")
        } finally {
            isLoading = false
        }
    }

    if (isLoading) {
        CircularProgressIndicator(modifier = Modifier.align(Alignment.Center))
    } else {
        LazyVerticalGrid(
            columns = GridCells.Fixed(2),
            contentPadding = PaddingValues(8.dp)
        ) {
            items(images) { imageItem ->
                ImageCard(imageItem)
            }
        }
    }
}
